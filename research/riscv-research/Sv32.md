#risc-v 
uses and is activated by the [[SATP Reg]]

Supported when **[[SXLEN]]=32**

In this mode, **supervisor and user virtual addresses** are translated into **supervisor physical addresses** by traversing a [[radix-tree page table]].

## General process
Sv32 virtual address partitioned into a 20-bit **virtual page number (VPN)** and a **page offset** 

![[Pasted image 20260803195444.png]]

The Sv32 virtual address is translated into a supervisor physical address via a 2-level page table. 

The 20-bit VPN is translated into a 22-bit [[PPN]], with the 12-bit offset staying untranslated.

![[Pasted image 20260803201046.png]]


The resulting s**upervisor-level physical address** is then checked using any **memory protection structures**, before being directly converted to a **machine-level physical address**

## Page table structure
- Sv32 page tables consist of 2^10 page-table entries (PTEs), each of **4 bytes** or **32 bits.** Therefore an Sv32 page table is 2^10 x 4 = 4096 bytes in size, or 1 KiB, which is the size of a **page in memory.**
- A page table is exactly the size of a page, and must always be aligned to a page-boundary.
